步驟一：處理套件依賴與虛擬環境（.venv）
請將以下提示詞貼給 AI：
「你現在是資深 Python 後端工程師。我要開發一個類似校務系統的專案。我已經在專案資料夾建立好名為 .venv 的虛擬環境。
	1.	請幫我列出開發這個系統（包含後端 API 與測試工具，例如 FastAPI、SQLAlchemy、pytest 等）需要用到哪些依賴套件。
	2.	請產出 requirements.txt 的內容。
	3.	請給我『啟動 .venv 虛擬環境』以及『安裝 requirements.txt』的具體終端機（Terminal）指令。
請用最白話的方式，一步一步告訴我該輸入什麼指令。」

步驟二：設計資料庫與藍圖（不動程式碼）
請將以下提示詞貼給 AI：
「我們現在要設計資料庫結構。請幫我設計『學生』、『課程』與『選課紀錄』三個資料表。
	1.	請清楚列出每個欄位名稱、資料型態（字串、整數、布林值等），以及主鍵（Primary Key）與外鍵（Foreign Key）的關聯。
	2.	請用 Markdown 表格呈現。
	3.	這個階段先不要寫任何資料庫連線的程式碼，我們只要確認藍圖。」

步驟三：開發單一功能 ＋ 單元測試（邊寫邊測）
請將以下提示詞貼給 AI：
「現在我們要實作『學生選課』的後端 API。請幫我寫出完整的 Python 程式碼，並且必須同時提供這個功能的單元測試（Unit Test）。
具體要求：
	1.	功能邏輯：檢查學生是否重複選課、檢查課程是否滿檔。成功則寫入資料庫，失敗則回傳錯誤訊息。
	2.	單元測試：請使用 pytest 寫出對應的單元測試程式碼，測試『選課成功』、『重複選課被擋』、『人數額滿被擋』三種情況。
	3.	防呆註解：每一行關鍵的程式碼和測試邏輯，都要加上繁體中文註解，把我當初學者一樣解釋清楚。
	4.	請告訴我在 .venv 環境下，執行這個單元測試的終端機指令是什麼。」

步驟四：開發前端介面（串接測試好的後端）
請將以下提示詞貼給 AI：
「後端 API 和單元測試已經完成了。現在我們要刻一個簡單的前端『選課操作畫面』。
	1.	請用基礎的 HTML + JavaScript (Fetch API) 幫我寫一個頁面，可以輸入學號並點擊按鈕呼叫剛剛寫好的選課 API。
	2.	請讓畫面的排版乾淨整潔，API 回傳成功或失敗時，要在畫面上跳出明顯的提示訊息。
	3.	請加上白話文註解，告訴我這個 HTML 檔案要怎麼跟後端連動。」

步驟五：整體完工後的系統測試（端到端測試）
請將以下提示詞貼給 AI：
「現在我們的前端畫面和後端 API 都已經組裝完畢了。我要做一次完整的『系統測試（System Test）』。
請幫我寫一支整合測試腳本（例如使用 pytest 搭配 Playwright 或是 Selenium，請選擇最適合且好設定的工具）。
測試情境（模擬真實學生操作）：
	1.	打開前端網頁。
	2.	輸入學號與課程代碼。
	3.	點擊送出按鈕。
	4.	驗證網頁畫面上是否正確顯示『選課成功』的訊息，並且去資料庫檢查有沒有這筆資料。
請給我完整的測試程式碼，並告訴我需要用 pip 補安裝什麼套件，以及具體的執行指令。註解一樣要非常白話易懂。」
